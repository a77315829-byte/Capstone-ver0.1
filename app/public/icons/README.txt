- clock.svg             : 과거 시나리오 / 히스토리

- compare-arrows.svg    : AI라면 비교 탭
- bar-chart-orange.svg  : AI 판단 분포
- flag.svg              : 중요 요인
- pencil.svg            : 내 판단 다시 선택
- check-orange.svg      : 일치/완료 상태
- warning.svg           : 주의/부정 신호
