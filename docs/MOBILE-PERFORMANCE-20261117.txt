ANTITUDE 모바일 및 마이페이지 투자성과 보완 / 2026-11-17

손실 누락 원인과 수정
- 국내 portfolio의 totalProfitLoss가 보유분 평가손익만 반환하여 손절 후 전량 매도하면 0으로 보였음.
  현금 + 현재 보유 평가금액 - 최초 원금 - 순입금액으로 계산하여 실현손익까지 유지.
- 성과 그래프가 최근 주문 50건과 initialCash만 사용했음. 신규 계좌 initialCash=0이고
  충전금은 totalDeposits에 쌓여 수익률 그래프가 0으로 고정될 수 있었음.
  전체 체결 이력의 일별 실현손익과 실제 입금 원금을 조회하고 현재 점에는 평가손익까지 반영.
- 손익 이력/거래 횟수는 최근 주문 목록의 50건 제한과 분리하여 집계.
- 원화/달러 왕복 환전이 같은 돈을 새 원금으로 중복 계산하지 않도록 양쪽 계좌의
  시간순 순입금 원금 최고값을 수익률 분모로 사용. 기존 원장 없는 입금도 보존.
- 전량 매도/전액 환전 뒤에도 손익과 수익률 유지. 기존 계좌의 잔액이나 거래 원장을 변경하는
  데이터 마이그레이션은 하지 않음. 조회 계산과 화면 연결을 수정한 것임.

마이페이지 연결/문구
- 화면이 보일 때 30초마다 갱신. 매매/환전 이벤트, 탭 복귀 및 전체 새로고침에 국내/미국 자산 갱신.
- 손익비를 매도 이익 평균 / 매도 손실 절댓값 평균으로 계산. 표본이 부족하면 '-' 표시.
- 보유 수익률은 보유 원가로 가중 계산. '평균 보유 종목 수' 등 실제 값과 맞지 않는 문구 수정.
- 총 계좌 수익과 현재 보유분 평가손익을 구분. 미국 총 손익에도 매도 손익이 포함됨을 표시.
- 최근 주문 표에서 미체결/취소/거절을 체결로 오해하지 않도록 상태 표시.
- AI처럼 표시되던 자산 비중 규칙 설명은 '보유자산 점검'으로 표시.
- 근거 없이 고정되었던 사이드바 '3일 연속 학습' 문구를 일반 학습 안내로 변경.
- 시세 실패 때 매입가 임시 계산임을 안내. 계좌 조회 실패를 0원 자산으로 표시하지 않음.
- 시나리오 진행 턴 및 퀴즈 기록의 사용자 매핑을 테스트 계정으로 확인.

모바일 변경 범위
- 768px 미만에서 상단 검색창을 한 줄 전체 너비로 배치. 긴 계정명은 화면 폭 안에서 줄임.
- 모바일 보유주식 버튼을 아래로 이동하여 주문 버튼을 가리지 않게 함. 패널은 상단부터 열림.
- 모바일 페이지/종목 이동 시 맨 위에서 시작. PC 스크롤 동작은 유지.
- 마이페이지 카드 최소 너비와 숫자 줄바꿈 보완. 표는 카드 안에서 좌우 스크롤.
- 모바일 성과 그래프 글자를 읽을 수 있게 좌표계를 조절하고 큰 손실에도 축 눈금 표시.
- AI 설명의 작은 글씨를 모바일에서 확대. 시장 AI의 긴 키워드도 화면 안에서 줄바꿈.
- PC의 화면 배치·색상·차트/주문 위치 유지. 데이터 정확성을 위한 문구·수치는 PC에도 반영.

검증
- 최종 npm test: 81개 통과, 실패 0. 서버 TypeScript와 웹 production 빌드 성공.
- 국내 통합검사 6개: 실제 HTTP 예약 주문/취소 및 장 마감 시장가 차단,
  통제된 가격으로 매수/부분매도/전량손실매도, 124건 전체 이력 및 별도 프로세스 DB 재조회.
- 미국 통제 검사 4개: 여러 매수가격의 원가, 부분 매도, 손실 전량 매도, 전액 환전 후 손익 유지.
- 모바일 브라우저에서 임시 계정으로 원화 300,000원 → USD 224.46 환전,
  SOXL 1주 매수/매도 → USD 224.52 → 원화 300,070원 환전 완료.
  API 대조 결과 USD 0, 미국 보유 0주, 실현손익 +USD 0.06, KRW 잔액 580,070원 일치.
- 모바일 AI 라면 최근 판단/근거 표시와 시장 시뮬레이터 실제 AI 분석 완료 화면 확인.
- 마이페이지 320/390/430/1440/1920px에서 페이지/카드/버튼 가로 넘침 없음.
- 시나리오 TURN 1/6 및 퀴즈 1/360, 정답률 100% 저장·조회·화면 표시 일치.
- 검증 후 직접 만든 임시 계정과 그 계정의 거래·환전·학습 기록만 정리 완료.
- 최종 doctor: 웹/DB, 시나리오, 시장 AI, AI 판단, Ollama 모두 정상 응답.

서버를 계속 켜야 하는지
- 매매·입출금·환전 기록은 DB에 저장되므로 서버를 껐다 켜도 손익은 재계산됨.
  이번 손실 누락의 주원인은 서버 가동 시간이 아니라 위 계산/표시 오류였음.
- 서버가 꺼져 있는 동안 AI 감시/새 분석과 실시간 시세 수집은 중단됨.
- 과거의 매 순간 평가손익은 저장되어 있지 않으므로 임의로 복원하지 않음.
  그래프에 '과거는 실현손익, 현재는 평가손익 포함' 기준을 명시함.

검증 한계
- 휴대폰 크기의 데스크톱 브라우저에서 조작한 결과이며 사용자의 실제 휴대폰 원격 검증은 아님.
  iOS/Android의 가상 키보드, 기기별 브라우저 차이는 실제 휴대폰에서 추가 확인 가능.
- 현재 국내 장 마감으로 실제 시세 시장가 체결 검사는 미국에서 수행. 국내 체결 가격 검사는
  별도 테스트 프로세스에서만 통제하였고 실행 서버의 장 시간/실제 시세 설정은 변경하지 않음.
- 기존 프런트엔드 전체 타입 검사 오류는 남아 있음. production 빌드와 이번 수정 경로를 검증함.
- 실제 AI 분석은 모델/PC 부하에 따라 시간이 걸리며 실패 시 기존 알고리즘 대체는 유지.
