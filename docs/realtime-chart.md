# 국내 주식 실시간 차트

`/exchange`의 국내 주식 화면은 **1일(일봉)**로 시작합니다. 유니티의 구간 조회 방식을 반영해 처음에는 최근 100개 봉을 요청하고 화면에는 최근 60개를 표시합니다. 왼쪽으로 이동하면 이전 120개 봉을 추가 조회합니다. KIS KRX 실시간 체결(`H0STCNT0`)로 현재 봉과 거래량을 갱신하며, 기존 Node 서버에서 처리합니다.

## 실행과 설정

프론트와 Node 서버를 다시 시작합니다. 서버의 기존 `.env`에서 다음 값을 사용합니다. 실제 환경 파일은 이 변경에서 수정하지 않습니다.

```dotenv
STOTRA_KIS_APP_KEY=발급받은_앱키
STOTRA_KIS_APP_SECRET=발급받은_앱시크릿
STOTRA_KIS_ENV=real
STOTRA_KIS_MARKET_DIV_CODE=J
```

`demo` 환경은 모의투자용 접속 주소를 사용합니다. 실시간 제공 범위와 접속 가능 여부는 해당 KIS 환경에 따릅니다. 앱키와 실시간 접속키는 브라우저로 전달하지 않습니다.

개발 환경에서는 Vite의 `/api` 프록시가 WebSocket을 함께 전달합니다. 배포 환경에서도 `/api/stocks/{6자리 종목코드}/stream`에 대한 WebSocket Upgrade 전달이 필요하며, 브라우저의 Origin과 일치하도록 원래 Host를 보존해야 합니다. 장이 닫혀 있거나 해당 종목에 체결이 없으면 새 봉은 발생하지 않습니다.

## 처리 흐름

- `GET /api/stocks/:symbol/candles?interval=1d&limit=100`: 초기 구간을 요청합니다. 응답은 `data`, `cumulativeVolume`, `snapshotDate`, `hasMore`, `nextCursor`를 포함합니다.
- `before=nextCursor&limit=120`으로 과거 구간을 조회합니다. 커서는 봉의 시작 시각(UNIX 초)이며 해당 시각보다 이전 봉만 반환합니다. 전체 기간을 자동으로 내려받지 않습니다.
- 과거 구간이 추가되어도 기존 봉과 최신 체결을 보존하고, 화면 이동 위치를 보정합니다. `최신으로` 버튼은 최근 60개 봉으로 돌아갑니다.
- `1일·1주·1개월·1년`은 조회 기간이 아닌 실제 봉 단위입니다. KIS의 `D·W·M·Y` 구분을 사용합니다. 분봉은 당일 시세를 요청해 선택한 단위로 묶으며, 당일 조회 범위를 벗어나는 과거 분봉은 제공하지 않습니다.
- 같은 구간의 동시 요청은 서버에서 공유하고, 최근 구간은 1분, 과거 구간은 6시간 캐시합니다. MongoDB에 연결되어 있으면 저장된 구간을 재사용합니다.
- `WS /api/stocks/:symbol/stream`: 접속 상태와 실제 체결 시각·가격·체결량·누적 거래량을 전달합니다. KIS 연결 하나에서 최대 40개 종목을 공유하고, 같은 종목을 보는 여러 화면에는 동일 데이터를 전달합니다.
- 브라우저는 수신 체결을 최대 초당 10회로 묶어 화면에 반영합니다. 같은 가격의 체결도 거래량에 반영하며, 중복 체결과 늦게 도착한 이전 체결은 제외합니다.
- 서버와 브라우저 모두 연결 실패 시 최대 30초 간격까지 지연을 늘리며 재접속합니다. 복구 시 최근 구간만 다시 조회하고 이미 불러온 과거 구간은 유지합니다.
- 차트 객체는 종목·시간 단위가 바뀔 때 생성하고, 체결 수신 때는 마지막 봉만 `update()`합니다. 확대·이동 위치를 유지합니다.

국내 과거 봉과 실시간 체결은 실제 한국 시간대의 UNIX timestamp로 통일했습니다. 기존 MongoDB 차트 캐시는 `timestampVersion=2`인 경우만 재사용하며, 이전 형식은 조회할 때 다시 채웁니다. 미국 주식 차트의 시간 변환은 변경하지 않습니다.

## 검증

```powershell
# server 디렉터리
npm run test:realtime
npx tsc --noEmit

# app 디렉터리
npm run test:chart
npm run build
```

`test:chart`는 Node의 TypeScript 실행 기능을 사용하므로 Node 22.18 이상이 필요합니다. 테스트는 가짜 체결과 로컬 서버를 사용하며 실제 KIS나 MongoDB에 접속하지 않습니다.

화면 검증용 시세는 `server`에서 아래 명령으로 실행할 수 있습니다. 이 미리보기는 가상 시세이며 실제 가격 검증용이 아닙니다. 포트 25310·25311·25373을 사용합니다.

```powershell
node -r ts-node/register tests/previewRealtime.cjs
```

미리보기 주소: `http://127.0.0.1:25373/exchange`
