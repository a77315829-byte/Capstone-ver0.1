AI 라면의 남은 제약
- 기존 AI 판단용 MongoDB 주소가 유효하지 않아 /health는 degraded/unavailable.
- 올바른 DB 설정을 받기 전에는 실제 판단 이력 저장·누적은 사용할 수 없음.
- 규칙 기반 대체 분석은 정상 표시되며 대체 결과를 실제 AI 이력으로 만들지 않음.
- DB를 사용하지 않는 별도 모델 호출에서 qwen2.5:1.5b 판단 해설 생성 5.22초 확인.
  이것은 모델 동작 검증이며 DB를 포함한 판단/이력 전체 경로의 통과를 뜻하지 않음.
- 패널을 열면 선택 종목 감시 등록, 30초마다 유지 요청. 닫으면 감시 해제.
  비정상 종료 시 유지 요청이 끊긴 뒤 약 60초 후 만료. 현재 서버만 켜면 수집되지 않음.
- 첫 조회 때 과거 일봉/수급을 가져와 분석하므로 사전 장시간 실행이 필수는 아님.
- DB 연결 후에는 기존 기록이 서버 재시작으로 지워지지 않음. 누적은 모델 학습이 아님.
