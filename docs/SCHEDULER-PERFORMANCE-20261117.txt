ANTITUDE 자동체결 및 국내·미국 통합 투자성과 / 2026-11-17

자동체결
- 국내·미국 스케줄러 파일은 있었으나 서버 시작 시 호출되지 않던 누락 수정.
- DB 연결과 웹 기동 후 시작 시 1회, 이후 기본 30초마다 자동 검사.
- 브라우저 없이도 정규장에 매수(조회 현재가 <= 지정가), 매도(현재가 >= 지정가) 모의체결.
- 정규장 외에는 예약 유지. 시세 실패 때 체결하지 않고 다음 검사에서 재시도.
- 중복 시작/검사 방지. 종료 시 타이머 중지 및 진행 중 검사 종료 대기.
- /api/health의 orderSchedulers.KR/US로 실행 여부 및 간격 확인 가능.
- 실제 주문장 매칭이나 시간외 거래를 구현한 변경은 아님.

투자성과
- 상단 자산·매매손익·수익률·거래 횟수·보유 종목 수에 국내/미국 계좌 합산.
- 미국 금액과 미국 실현손익은 조회 환율로 원화 참고 환산. 기준일/지연 상태 표시.
- 매매손익은 실현손익과 보유 평가손익 포함, 환차손익 제외.
- 통합 원금에서 내부 환전을 제외하여 동일 자금 중복 집계 방지. 원장 이전 입금 보존.
- 국내/미국 전체 체결 이력 집계. 최근 주문 50건 제한은 성과에 적용하지 않음.
- 미국 계좌/환율 조회 실패 때 국내만으로 통합 총액을 표시하지 않고 안내.
- 미국 시세 실패 때 매입가 임시 평가임을 안내할 수 있도록 평가 성공 여부 추가.
- 국내 상세와 미국 상세는 각각 유지. PC 배치·색상 유지.

그래프
- 1주/1개월/3개월/6개월/1년: 최근 7/30/90/180/365일. 전체: 기록 시작부터 현재.
- 날짜 간 실제 간격을 가로축에 반영. 이전 누적 실현손익은 기간 시작점에 이월.
- 기록 시작 이전은 값 생성 안 함. 이력이 짧으면 여러 기간의 곡선이 비슷할 수 있음.
- 마우스/터치/방향키/Home/End로 날짜·손익률·원화 손익 조회.
- 과거는 누적 실현손익, 현재 점은 평가손익 포함. 수익률은 현재 투입원금 기준.
- 과거 평가자산/과거 환율을 복원한 그래프는 아님. 없는 과거 시세/손익을 생성하지 않음.

검증
- npm test 91개 통과, 실패 0. 서버 TypeScript 및 웹 운영 빌드 성공.
- 별도 임시 MongoDB와 빌드된 Node 서버에서 통합 검사 8항목 통과.
  시작 연결, 개장 전 대기, 국장/미장 개장 후 자동 매수, 가격 조건 미달,
  시세 장애/복구, 자동 매도, 중복 체결 방지, 마감 차단, 종료 처리 포함.
  합산 자산/손익/거래 횟수/환율 환산/사용자 격리/미인증 차단 포함.
- 테스트 서버의 시각/시세만 통제. 실제 거래소 장중 체결 관찰을 뜻하지 않음.
- 실행 전 비어 있음을 확인한 전용 임시 DB만 소유 표식 검증 후 정리. 기존 사용자 DB 유지.
- 합성 API를 쓰는 별도 헤드리스 브라우저에서 6개 기간과 날짜 범위 확인.
  양수/음수 툴팁, 키보드, 터치, 320/390/430/1440/1920px 넘침 없음 확인.
  실제 사용자의 휴대폰을 직접 조작한 검증은 아님.
- 실제 서버 재시작 후 웹/DB/시나리오/시장/판단/Ollama 모두 OK,
  국장 및 미장 스케줄러 running=true, intervalMs=30000 확인.
- 기존 전체 프런트 타입 검사 오류 및 번들 크기 경고는 남아 있음.

거래시간 및 배포 범위
- 정규장 자동 모의체결만 수정. 국내 시간외·KRX/NXT 애프터마켓,
  미국 프리/애프터마켓의 시세·체결 규칙은 아직 지원하지 않음.
- 실제 시장에는 정규장 이후 세션이 있으므로 정규장 마감은 전체 거래 종료와 다름.
- 학교용 .env 4개 유지. 설치/단일 실행 절차 동일. 최신 ZIP을 새 폴더에 풀어서 사용.
