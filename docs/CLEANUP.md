DB 컬렉션은 삭제하지 않았습니다. 기존에 급여 계획으로 자동 입금하도록 설정한 계정은 새 코드에서 **더 이상 월 입금이 실행되지 않지만**, 현재 잔액 및 누적 입금액은 DB에 남습니다. 로그인 및 실시간 데이터에는 기존 Atlas/KIS/Turnstile 키가 필요합니다. 서비스마다 DB와 외부 API가 달라서 HTTP 헬스 체크만으로 화면의 실제 거래나 채점을 보증하지 않습니다.

남은 검증 조건: 실제 사용자 `.env` 및 MongoDB 데이터로 로그인→국내·미국 화면→시나리오 세션→턴 제출→AI 판단을 통과하는지 확인. 민감한 키와 DB 값을 저장소에 복사하지 않으므로 이 검증은 사용자 환경에서 수행해야 합니다.
